# 📝 MindPad

A simple and interactive Notes App built using **React.js** that allows users to create, view, edit, and delete notes. All notes are saved in **localStorage**, ensuring your data persists even after page reloads.

---

## 🚀 Features

### ✅ Core Features
- 🆕 **Add a Note** — Create a new note with a title and content.  
- 📋 **Display Notes** — View all your saved notes in a clean layout.  
- ❌ **Delete Notes** — Remove any note permanently.  
- 💾 **Persistent Storage** — Notes are stored in `localStorage` so they stay after refreshing or reopening the app.

---

## 🌟 Bonus Features
- ✏️ **Edit Notes** — Update the title or content of an existing note.  
- 🔍 **Search Notes** — Instantly find notes by title or keyword.  
- 🪟 **Modal for Editing** — Use a popup modal to edit notes smoothly.  
- 🌗 **Light/Dark Mode** — Toggle between light and dark themes for better user experience.

---

## 🧰 Tech Stack

- **Frontend:** React.js  
- **Styling:** CSS / TailwindCSS  
- **Storage:** Browser LocalStorage

## ⚙️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/notes-app.git
   ```
2. **Navigate into the project directory**
   ```bash
   cd notes-app
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Start the development server**
   ```bash
   npm start
   ```

5. Open your browser and visit 👉 http://localhost:3000
